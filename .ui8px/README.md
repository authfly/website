# ui8px policy

Copied unchanged from authfly/cli `.ui8px/policy` (generated by `npx ui8px init`: 8 px layout steps, 4 px steps inside
controls, plus `underline`, `underline-offset-4`, `auto-rows-min`, `size-4`, `size-5`, which the UI8Kit templ
primitives use). The site adds no utilities: document-level rules that have no utility in this policy (page height,
font smoothing, anchor offset) live in `styles/site.css`. Run `bunx ui8px lint`; it must report 0.
