# Что такое Authfly

Authfly — собственный слой идентификации для ваших приложений. Он работает рядом со **Stalwart**, почтовым сервером с открытым кодом, встроенным каталогом пользователей и OpenID Connect-провайдером, и добавляет всё, что приложению нужно вокруг учётных записей:

- регистрацию (по умолчанию по приглашению), вход по паролю, имени пользователя или magic-ссылке;
- подтверждение почты, сброс пароля, выход на всех устройствах;
- личный кабинет: профиль, выгрузка данных, удаление аккаунта, согласия и журнал действий;
- OpenID Connect-провайдер для единого входа (SSO) в ваши приложения (authorization code с PKCE);
- пакеты политик с техническими настройками под GDPR, законы США о персональных данных (CCPA/CPRA) или 152-ФЗ.

Учётные записи пользователей — это почтовые ящики в Stalwart. Authfly никогда не открывает наружу API управления Stalwart: из интернета видны только Authfly и почтовые порты.

## Одна система, 9 платформ

Шесть одинаковых виджетов (вход, регистрация, запрос, уведомление, согласие, кабинет) рендерят один и тот же HTML на девяти рантаймах, на примитивах UI8Kit 3:

| Семейство | Рантаймы |
|---|---|
| JavaScript | React, Vue 3, Svelte 5, Solid, Web Components |
| Go | templ |
| PHP | Twig, Latte |
| Python | Jinja2 |

Каждый виджет читает только флаги возможностей одного контракта, `@authfly/core`, поэтому смена фронтенда не меняет бэкенд. См. [Платформы](/ru/targets).

## Как всё связано

| Часть | Репозиторий | Роль |
|---|---|---|
| CLI и сервер `authfly` | authfly/cli | `npx authfly init` / `deploy`: генерирует конфигурацию, секреты и контейнеры; отдаёт страницы входа, JSON API и OIDC-эндпоинты |
| Контракт и SDK | authfly/authfly | `@authfly/core` (одна JSON-схема), серверные SDK для TypeScript, Go, Python и PHP |
| Виджеты | authfly/authkit | шесть виджетов для девяти рантаймов, ставятся через `npx ui8kit@3 add` из реестра Authfly |
| Stalwart | stalwartlabs/stalwart | учётные записи, почта, подпись OIDC; закрыт за Authfly |
